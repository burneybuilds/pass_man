# PassMan

PassMan is a local password management tool.

## Why I Built This

Like a lot of people learning Python, I could have built another CRUD application. I didn't really want to make something just because everyone else was making it.

For a long time, I kept all of my passwords in a notebook. It worked, and in some ways it's safer because it's offline. The problem was that every time I needed a password, I had to find the notebook, flip through the pages, read the password, and type it in manually.

I wanted something that fit better into how I already use my computer.

So I built PassMan.


Note :- This isn't meant to replace professional password managers. It's a personal project that solves a problem I actually had while helping me learn by building something I would use.
